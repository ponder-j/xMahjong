XMahjong完整 OpenAPI JSON

本地 API 参考

所有牌谱和模型数据均保存在本机。API 不提供公网鉴权；默认仅支持 localhost。完整请求结构见 OpenAPI JSON。

方法路径用途
GET/api/health引擎配置状态与非敏感 LLM 配置
GET/api/replays本地牌谱库
POST/api/replays/importmultipart file，天凤6 JSON 或 MJAI，最大 12 MiB
POST/api/replays/linkJSON {url}，下载雀魂牌谱
POST/api/replays/example加载上游真实天凤样本
GET/api/replays/{id}/decisions?actor=0决策列表，actor 为 0–3
GET/api/replays/{id}/decisions/{decision}?actor=0仅含所选视角可见信息的局面
POST/api/replays/{id}/decisions/{decision}/analyze?actor=0双引擎真实输出、合理候选并集与独立证据
POST/api/replays/{id}/decisions/{decision}/explain?actor=0逐候选 LLM 解释及证据校验
POST/api/replays/{id}/decisions/{decision}/chat?actor=0JSON {question, history}；基于同一局面的追问
POST/api/replays/{id}/decisions/{decision}/counterfactual?actor=0JSON {tile}；合法弃牌的单步证据实验
GET/api/replays/{id}/mjai导出完整原始事件流，仅供用户显式下载
POST/api/settings/llmJSON {base_url, model, api_key?, thinking_compatibility}；原子保存到本机，重启自动恢复
POST/api/settings/llm/test实际调用 /chat/completions 检查当前模型

analyze 返回 status=unconfigured / timeout / error 时不包含虚构评分。LLM 失败返回 source=computed，notice 说明回退原因。反事实返回即时牌效证据，不重用原牌谱的未来结果。
